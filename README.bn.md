## 📖 পরিচিতি

GitHub File Manager এমন একটি অ্যাপ যা মোবাইল ডিভাইস থেকেই GitHub রিপোজিটরি, ফাইল ও ডিরেক্টরি পরিচালনা, কোড এডিট এবং ফাইল আপলোডের পূর্ণ স্বাধীনতা দেয়।

পিসির ব্রাউজারে না গিয়ে সরাসরি স্মার্টফোন থেকে যেকোনো **Private** বা **Public** রিপোজিটরির ফাইল পরিবর্তন, নতুন ফাইল তৈরি, ZIP এক্সট্র্যাক্ট করে আপলোড এবং ব্রাঞ্চ ম্যানেজমেন্টের কাজ সহজে করার জন্য এই অ্যাপটি তৈরি করা হয়েছে।

## ✨ ফিচারসমূহ

### 👥 মাল্টি-অ্যাকাউন্ট সাপোর্ট
- একাধিক GitHub অ্যাকাউন্ট (Personal, Work, Organization) সেভ করে রাখা যায়
- এক ক্লিকেই অ্যাকাউন্ট পরিবর্তন (Switch)

### 🗂️ রিপোজিটরি ব্রাউজার
- পাবলিক ও প্রাইভেট সব রিপোজিটরির তালিকা
- রিপোজিটরি সার্চ, স্টার ও ফর্ক সংখ্যা, ডিফল্ট ব্রাঞ্চ এবং শেষ আপডেটের সময় দেখা
- যেকোনো ব্রাঞ্চ সিলেক্ট করে ফাইল ব্রাউজ করা

### 🌳 রিকার্সিভ ফাইল ট্রি ও ফাইল ম্যানেজার
- ফোল্ডার ও সাব-ফোল্ডারের বিস্তারিত ট্রি এবং গ্রিড/লিস্ট ভিউ
- ফাইল সার্চ ও ব্রেডক্রাম্ব (Breadcrumb) নেভিগেশন
- ফাইল টাইপ অনুযায়ী আইকন (Code, Markdown, Image, PDF, Config ইত্যাদি)

### ✏️ ইন-বিল্ট কোড এডিটর ও কমিট সিস্টেম
- অ্যাপ থেকেই কোড ও টেক্সট ফাইল এডিট
- কাস্টম Commit Message দিয়ে সরাসরি GitHub-এ কমিট পুশ
- Unsaved changes ট্র্যাকিং, যাতে কাজ হারানোর ঝুঁকি না থাকে

### 📝 লাইভ মার্কডাউন প্রিভিউয়ার
- `README.md` ও যেকোনো `.md` ফাইলের GitHub-স্টাইল রেন্ডারিং ভিউ

### 📦 ZIP আপলোডার ও এক্সট্র্যাক্টর
- মোবাইল থেকে ZIP ফাইল সিলেক্ট করে রিপোজিটরির যেকোনো ফোল্ডারে স্বয়ংক্রিয়ভাবে এক্সট্র্যাক্ট করে একবারে আপলোড

### 🗑️ বাল্ক ডিলিট ও ফাইল অ্যাকশন
- একসাথে একাধিক ফাইল সিলেক্ট করে বাল্ক ডিলিট
- ফাইল রিনেম, নতুন ফাইল ও নতুন ডিরেক্টরি তৈরি

### ⚡ অফলাইন ক্যাশিং ও অপ্টিমাইজড নেটওয়ার্কিং
- মেমরি ক্যাশিং ও দ্রুতগতির Retrofit নেটওয়ার্ক কলের মাধ্যমে দ্রুত ডেটা লোডিং

## 🚀 শুরু করার নিয়ম

1. উপরের লিংক থেকে অ্যাপটি ডাউনলোড ও ইন্সটল করুন।
2. নিচের লিংকে ক্লিক করে প্রি-কনফিগার্ড স্কোপসহ GitHub Personal Access Token (PAT) তৈরি করুন:

   👉 [**টোকেন তৈরি করুন**](https://github.com/settings/tokens/new?scopes=repo,read:user,user:email,workflow&description=GitHub%20File%20Manager%20App)

3. টোকেনটি কপি করে অ্যাপে পেস্ট করে লগইন করুন।

পূর্ণাঙ্গ নির্দেশিকা: [Setup Guide & Blog](https://imalimrans.pages.dev/blog-posts/GithubFileManagerapk)

## 🔑 টোকেন পারমিশন (Scopes)

| Scope | কেন প্রয়োজন |
|-------|--------------|
| `repo` | প্রাইভেট ও পাবলিক রিপোজিটরির ফাইল দেখা, এডিট, তৈরি ও ডিলিট করার জন্য |
| `read:user` | প্রোফাইল নাম, ইউজারনেম ও অ্যাভাটার প্রদর্শন এবং অ্যাকাউন্ট নিশ্চিত করার জন্য |
| `user:email` | কমিট করার সময় Git Authorship হিসেবে আপনার GitHub ইমেইল যুক্ত করার জন্য |
| `workflow` | `.github/workflows` ফোল্ডারের CI/CD কনফিগারেশন ফাইল এডিট করার জন্য |

## ⏳ টোকেনের মেয়াদ

GitHub নিরাপত্তার স্বার্থে ক্লাসিক টোকেনে ৩০/৬০/৯০ দিন এবং ফাইন-গ্রেইন্ড টোকেনে নির্দিষ্ট মেয়াদ নির্ধারণ করে, যাতে টোকেন অসাবধানতায় ছড়িয়ে পড়লেও মেয়াদ শেষে অকার্যকর হয়ে যায়।

**মেয়াদ শেষ হলে কী হবে?**
1. GitHub API `401 Unauthorized` বা `Bad credentials` ত্রুটি রিটার্ন করবে।
2. অ্যাপে ফাইল লোড বা এডিটের সময় টোকেন এক্সপায়ার্ড হওয়ার স্পষ্ট নোটিশ দেখানো হবে।
3. **Settings → Update Token** এ গিয়ে নতুন টোকেন পেস্ট করলেই সাথে সাথে পুনরায় কানেক্ট হবে — অ্যাকাউন্ট রিমুভ বা অ্যাপ আনইনস্টল করার দরকার নেই।

**মেয়াদ যাতে শেষ না হয়:**
GitHub Settings → Personal Access Tokens (Classic) → **Expiration** ড্রপডাউন থেকে **No expiration** সিলেক্ট করে টোকেন জেনারেট করুন।

> ⚠️ নিরাপত্তার জন্য টোকেনটি সম্পূর্ণ গোপন রাখুন এবং কারো সাথে শেয়ার করবেন না।

## 🔒 নিরাপত্তা ও আর্কিটেকচার

- **জিরো থার্ড-পার্টি সার্ভার:** কোনো ব্যাকএন্ড সার্ভার বা মিডলম্যান ডেটাবেজ নেই। সমস্ত যোগাযোগ আপনার ফোন ও অফিসিয়াল GitHub REST API (`https://api.github.com`)-এর মধ্যে সরাসরি, HTTPS/TLS এনক্রিপ্টেড মাধ্যমে ঘটে।
- **লোকাল প্রাইভেট স্টোরেজ:** আপনার PAT ও অ্যাকাউন্টের মেটাডেটা শুধুমাত্র ডিভাইসের প্রাইভেট `SharedPreferences`-এ সংরক্ষিত থাকে। অ্যাপ ছাড়া ফোনের অন্য কোনো অ্যাপ বা বাইরের কেউ এটি পড়তে পারে না।
- **ওপেন-সোর্স ট্রান্সপারেন্সি:** সম্পূর্ণ কোড Kotlin + Jetpack Compose-এ লেখা এবং GitHub-এ উন্মুক্ত। কমিউনিটির যে কেউ কোড অডিট করতে পারে — কোনো ব্যাকডোর বা ডেটা ট্র্যাকিং নেই।
